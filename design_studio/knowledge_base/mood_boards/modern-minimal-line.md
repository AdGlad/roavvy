# Mood Board — Modern Minimal Line

**Feeling:** quiet, contemporary, everyday — the tee you wear on a normal Tuesday.
Understatement as confidence.

**Palette (direction):** garment + one ink. Navy `#1E2A38` on white, or off-white
`#EDE8DF` on navy. Optional single micro-accent. *(R-COL-01/02/05; tone-on-tone
allowed as a deliberate niche — R-COL-03 exception)*

**Typography:** one clean grotesque; mixed case or lightly tracked caps; a mono
coordinate line as the only "detail" tier. Refined kerning. *(R-TYPE-01/02/05)*

**Texture / print style:** essentially none — crisp vector; `printStyle.id: clean`
(or `riso` for a subtle modern grain). Distress would cheapen it. *(R-TEX-01
exception; R-TREND-01 "pick a lane")*

**Layout archetype:** left-chest small mark *or* a spare centred outline/line-art;
maximum negative space. *(R-NEG-01/02, R-ICON-02)*

**Garment:** white, navy, heather grey.

**References:** `reference_images/liked/streetwear/` (clean, high-contrast,
restrained exemplars).

**Target genome:** `template: typography` (small mark) or `grid`+`countryOutline`
(single, line-art) · `palette.strategy: garmentAware|monochrome` ·
`printStyle.id: clean|riso` · `imageSize: small|medium`.

**Embodies:** R-NEG-01/02, R-ICON-02 (one strong simple mark), R-COL-01/02,
R-STORY-04 (insider understatement), R-TREND-03 (minimalism = timeless).

**Avoid:** any grunge/heavy distress (world mismatch); more than one accent; busy
detail that dies at left-chest scale; refined line-art rendered as a hairline that
won't print (R-PRINT-04).
