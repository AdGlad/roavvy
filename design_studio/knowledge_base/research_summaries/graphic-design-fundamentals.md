# Research Summary — Apparel Graphic-Design Fundamentals

*Stream 2 of 4. Composition, hierarchy, negative space, typography, colour, icons,
and layout archetypes — reasoned from apparel-specific constraints. Informs rules
R-VH-*, R-COMP-*, R-NEG-*, R-COL-*, R-TYPE-*, R-ICON-*, and the archetype map in
`topics/apparel-layouts.md`.*

## Why apparel is different (the constraints every rule serves)
The canvas is coloured, textured, moving and wrinkling — not a white screen. The
garment colour is always a design colour. Prints are judged first at ~1.5–3 m
(across a room) then up close on the rack. Print methods choke fine lines, band
gradients, fill thin knockouts, and mush tiny type. One glance decides
premium-vs-cheap; there is no hover, scroll or second screen.

## Rules (condensed; full set in `design_rules.md`)
- **One dominant element; 3-tier hierarchy (hero/support/detail); decisive scale
  contrast (~1.6–2×+).** Small size differences read as mistakes; large as
  confidence. → R-VH-01/02/03.
- **Gestalt grouping** (proximity/alignment/shared shape/frame) so parts read as
  one object. **Anchor to a containing shape + alignment grid.** → R-COMP-01/02.
- **Generous negative space = premium;** cramped = cheap. **Contain the print**
  (~25–30 cm, high-center; left-chest ~7–10 cm). → R-NEG-01/02.
- **Garment colour is an active ink.** **Limit palette 2–4 (incl. garment).**
  **Luminance contrast, not hue, carries distance legibility.** **Tonal/duotone
  reads more premium** by default. **One disciplined accent.** **Coherent
  temperature story.** → R-COL-01..06.
- **Max two typefaces.** **Track caps/small; kern hero.** **Case matches intent.**
  **Clean arcs** (consistent radius, symmetric, even spacing). Don't stretch type
  non-uniformly; don't outline+shadow+bevel. → R-TYPE-01/02/03/04/07.
- **One consistent icon style/stroke.** **A single strong icon beats an
  illustration crowd.** → R-ICON-01/02.
- **Respect reproduction limits** (no hairlines, tiny knockouts, unbanded
  gradients) and **design for wrinkle/stretch/curvature.** → R-PRINT-04.

## Layout archetypes (reference)

| Archetype | Best for | Strengths | Pitfalls / size |
|---|---|---|---|
| Centered emblem/badge | Country + name + motif; heritage | Instantly premium; self-contained; the workhorse | Generic if overused; interior crowds fast; medium–large only |
| Stacked type lockup | Long/wordy names, taglines, coords | Handles variable length; strong hierarchy | Boring if timid contrast; alignment must be perfect |
| Arced banner | Short punchy names; varsity feel | Energetic; classic; pairs with a hero icon | Arc execution failure-prone; breaks long names |
| Circular seal/stamp | Passport concept; official tone | Very on-brand; ring holds arced text | Densest; dies small; long names won't fit |
| Left-chest small mark | Minimal/premium; one icon | Understated, expensive; cheap to print | Must be truly simple; placement consistency critical |
| Full-front scene | Illustrative maps/landscapes | Maximal impact; storytelling | Loses detail at distance/wrinkle; costliest; busy risk |
| Stamp/badge collage (grid) | "Places visited" multi-stamp | Repetition-as-concept; many at once | Only works if one shared style; each unit tiny |

**Selection heuristic:** short name+one motif → seal/arced banner; long name →
stacked lockup; single icon/premium → left-chest; multi-country → unified collage;
illustrative hero → full-front (sparingly).

## Typography do/don't (essentials)
DO: max two faces; pair by contrast-of-role/harmony-of-feel; track caps & small;
kern hero; big tier jumps; case matches tone; clean symmetric arcs; keep above
min legible cap height; condensed for long names, slab for rugged, script as
accent only. DON'T: 3+ display fonts / two scripts / two similar sans; track
scripts; long all-caps passages; rely on default kerning; near-equal tiers;
non-uniform stretch; outline+shadow+bevel; thin knockout type on knit.

## Colour do/don't (essentials)
DO: count the garment as an ink; 2–4 total; prioritise value contrast; default
tonal/duotone; one small accent; commit a temperature; muted + one richer note;
off-white on dark, dark on light; convert gradients to halftone. DON'T: design as
if on white; rainbow saturation; hue-only contrast; accent everywhere; random
warm/cool; harsh pure #000/#FFF on coloured garments; add inks "to add value".
