# Research Summary — Trends, Marketplaces & Flag/Travel Merch

*Stream 4 of 4. Apparel trends, Etsy/Redbubble/DTC success patterns, flag usage,
and travel storytelling. Informs rules R-FLAG-*, R-STORY-*, R-TREND-*, R-MERCH-*,
R-COMP-04, and `topics/flag-usage.md`, `topics/travel-storytelling.md`,
`topics/design-trends.md`.*

## Two cross-cutting truths
1. **Roavvy's moat = real personal data × a coherent premium system.** Every rule
   protects personalisation that still looks *designed* (systematic grid, palette
   limits, density tiers, composed-not-inserted) and a premium system robust to
   any data (one hero, muted palette, uniform grids, thumbnail-first).
2. **The central failure is "auto-generated smell,"** defeated by systematic
   constraint — never by adding decoration. **Emotion beats information:** a
   journey is worth wearing; an inventory is a database.

## Rules (condensed; full set in `design_rules.md`)
- **One hero;** **palette 2–4, derived not literal;** **one shared grid/geometry;**
  **negative space;** **identity claim over decoration.** → R-VH-01, R-COL-01/07,
  R-COMP-02, R-NEG-01, R-STORY-03.
- **Flag grids: ruthless uniformity, normalise aspect ratios** (flags vary wildly).
  **Country outline as a container, not a bare shape.** → R-FLAG-03, R-STORY-05.
- **Distress physically plausible, not decorative noise.** **Type as a rigorous
  graphic element.** → R-TEX-01, R-TYPE-05.
- **Compose personalised data, never insert it;** **≥3 density tiers per template**
  by data volume. → R-COMP-04, R-MERCH-02.
- **Nationalism-neutral by default;** **sensitivity as a data-layer concern** (a
  floor, not polish). → R-FLAG-04/05.
- **Sell the journey, not the inventory;** **coordinates/dates feel premium because
  they feel true.** → R-STORY-02/01.
- **One coherent aesthetic world per template; don't mix worlds.** **Optimise the
  thumbnail (won at 200px).** **Avoid oversaturated tropes** (wanderlust script,
  dotted world map, airplane+arc, compass clip-art). → R-TREND-01, R-COMP-03,
  R-TREND-04.

## Timeless vs fad

| Trend | Verdict | Why |
|---|---|---|
| Vintage/retro (halftone, sepia, faded) | **Timeless** | Perpetual nostalgia; distress hides print flaws; authenticity |
| Minimalism (single emblem, wide margins) | **Timeless** | Restraint = quality across eras; strong at thumbnail; cheap print |
| Heritage/"blokecore" (crests, collegiate, est.) | **Timeless-leaning** | Centuries-old badge tradition; the terrace framing is faddish |
| Coordinate/cartographic/expedition-log | **Timeless-leaning** | Nautical/archival roots; authentic; cliché risk if generic |
| Gorpcore/outdoor-technical (topographic) | **Medium** | Adopt the grammar, not the slogans |
| Streetwear graphic language | **Enduring but mutating** | Category permanent; motifs churn fast |
| Maximalism / collector walls | **Cyclical fad** | Hard to keep premium; costly; hero-only |
| Y2K / chrome / bubble | **Fad** | Strong spike, short cycle; dates fast |
| "Wanderlust" script + generic map | **Dead/oversaturated** | Undifferentiated, non-personal — avoid |
| Personalisation / "wear your identity" | **Timeless meta-trend** | Not a style — a demand driver; Roavvy's core edge |

## Flag usage — tasteful vs tacky

| Approach | Tasteful ✔ | Tacky ✘ | Why |
|---|---|---|---|
| Saturation | Muted/duotone/tonal/single-ink | All flags at 100% side by side | Flags clash violently en masse |
| Flag-in-outline | Colours inside the country silhouette | Flag stretched to fill the shirt | Containment gives form/meaning |
| Multi-flag | Uniform roundels/tiles, normalised aspect | Random pile of different sizes | Uniformity signals curation |
| Torn/ripped | One flag, one believable tear | Jagged random grunge rips | A real rip tells a story |
| Duotone | Two consistent tones across the set | Inconsistent across a mix | Consistency reads intentional |
| Montage | Dissolved into one shared texture/shape | Full-colour collage w/ shadows+bevels | Integration = premium |
| Framing | "Places I've been" | "Conquered/ranked" / nationalism | Journey framing is globally sellable |
| Disputed flags | Neutral fallback, curation, careful adjacency | Blind auto-render of any combo | Reputational landmines |

## Travel storytelling devices

| Device | Emotional hook | Works when | Risks |
|---|---|---|---|
| Journey line (visit order) | Narrative + time | Few–medium points | Spaghetti with many points; cliché if unstyled |
| Coordinates | Authenticity, archival romance | Coordinate/heritage, few locations | Fabricated precision kills trust; overused |
| Country/region outline | Recognition, pride | Single-country/region hero; as container | Bare outline = map-site cliché |
| Passport stamps | Nostalgia, collection | Medium counts; vintage worlds | Abstract not replicate; clutter without a grid |
| Checklist / "been there" | Achievement, completion | Identity-claim; any count | Spreadsheet feel without strong type |
| Itinerary / ticket | Anticipation, the artifact | Single-trip commemoratives | Boarding-pass motif overused |
| Count as hero ("47 · 6") | Pride, status; thumbnail-strong | Dense data | Cold/braggy without warm framing |
| Est. / "explorer since" | Identity, longevity | Heritage badge (support role) | Meaningless if fabricated |
| Region/continent fills | Scope, ambition | Region-level products | Coarse granularity can undersell |
| Worn passport/luggage object | Tangibility | Vintage/heritage hero | Skeuomorphism can tip to kitsch |
