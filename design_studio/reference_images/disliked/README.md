# reference_images/disliked

Counter-examples — designs the engine should **avoid** (muddy palettes,
unreadable titles, overcrowding, poor focal hierarchy, un-printable contrast).

Same rules as `../liked/`: one image per file, a sibling `reference_analysis`
record per image, provenance/rights logged, binaries git-ignored by default.

Negatives are as valuable as positives: they calibrate the scorers and provide
hard negatives for preference learning (`disliked` signal).
